 # University Student Clubs Portal

A responsive website showcasing university student clubs,
upcoming events, club achievements, and membership information.

## Technologies
- HTML5
- CSS3
- Git
- GitHub

## Pages
- Home
- Club Categories
- Upcoming Events
- How to Join
- Club Highlights

## Project Purpose
This project demonstrates collaborative Git and GitHub
workflows, including branching, pull requests, rebasing,
conflict resolution, and release management.
