# University Student Clubs Portal

## Project Overview
A responsive university student clubs website developed for DevOps Fundamentals Assignment 01.

## Website Pages
- Home — Introduction to the student clubs portal.
- Clubs — Available student clubs and categories.
- Events — Upcoming campus activities and events.
- Join Us — Club membership instructions.
- Highlights — Student club achievements.

## Technologies
HTML5, CSS3, Git, GitHub, Visual Studio Code.

## Git Branching Strategy
- `main` — Stable release branch.
- `develop` — Development integration branch.
- `production` — Production branch.
- `release/v1.0` — Version 1.0 release.
- `feature/*` — Individual feature development branches.

## Development Workflow
The project used GitHub Issues, feature branches, commits, Pull Requests, branch integration, and release management.

## Testing
Verify navigation among all five pages, responsive layouts, and shared stylesheet functionality before submission.

## Individual Development Note
This assignment was implemented individually. GitHub's required independent code reviews could not be completed by separate team members. Authorized branch protection bypasses were used where necessary and should not be represented as independent approvals.
